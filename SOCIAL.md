## Thread (6 posts)

1/ Computing progress isn’t only “more power.” It’s also doing the **same** verified work with **less energy**.

2/ Buy Inefficiency proposes a public, versioned **index**: a fixed basket of workloads + an energy measurement protocol. Method not prescribed. Chip not crowned.

3/ If new hardware, algorithms, or weird future substrates finish the same basket with fewer joules, the index should move — whoever built them.

4/ Specs can be forked. A fork is a new index. It doesn’t rewrite the original history. Legitimacy = transparency + reproducibility + adoption.

5/ Important: **index ≠ token**. Defining the measure does not create a tradable asset. Any exposure design would be a separate phase.

6/ v0.1 is public and free. Read, critique, propose workloads: https://github.com/giomariolasagna-ux/buy-inefficiency
