Public index specification

Buy Inefficiency

Measure computational progress as less energy for the same verified work — not more FLOPS, not a vendor ranking, and not a cryptocurrency product.

Index ≠ token. Defining the measure does not create a tradable asset. Any economic exposure design would be a separate later phase.

The system uses a public basket of workloads. Inputs, required results, and verification are fixed. The method is not. When new techniques finish the same basket with fewer joules, efficiency rises — whoever built them.

  • Versioned public specification
  • Forks allowed (each fork = a new index)
  • Legitimacy from transparency, reproducibility, adoption
